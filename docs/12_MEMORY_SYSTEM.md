# Traders World AI — Memory System

## Purpose

The Memory System allows the AI Copilot to maintain context across conversations while keeping the documented strategy as the single source of truth.

Memory improves continuity.

Knowledge improves intelligence.

The two should never be confused.

---

# Memory Layers

## Layer 1 — Working Memory

Duration:
Current message only.

Purpose:
Understand the immediate request.

Examples:
- Current chart
- Current question
- Current screenshot

Cleared after each interaction.

---

## Layer 2 — Conversation Memory

Duration:
Current chat session.

Purpose:
Maintain a natural conversation.

Examples:

User:
"We're looking at Gold on the 1H."

Later:

"Now switch to the 1m."

The AI understands both refer to the same market.

---

## Layer 3 — Trading Session Memory

Duration:
Entire trading session.

Stores:

- Symbol
- Timeframes
- HTF Bias
- Current setup
- Session notes
- Trades taken
- Mistakes identified

This allows the AI to coach throughout the session.

---

## Layer 4 — Long-Term Knowledge

Stored permanently in the Knowledge Base.

Includes:

- Strategy
- Rules
- Backtests
- Journals
- Psychology
- Case studies
- Glossary

This is the only layer used for strategy guidance.

---

# What the AI Should Remember

- Current discussion
- Active symbol
- Current timeframe
- Current learning topic
- Previous explanations
- User preferences (when appropriate)

---

# What the AI Should NOT Remember

- Temporary assumptions
- Undocumented strategy ideas
- Guesses
- Incorrect information

Everything important must be documented before becoming permanent knowledge.

---

# Memory Workflow

User speaks
      ↓
Working Memory
      ↓
Conversation Memory
      ↓
Trading Session Memory
      ↓
Knowledge Base (if intentionally documented)

Only documented information becomes permanent.

---

# Memory Retrieval Priority

1. Current message
2. Conversation context
3. Trading session
4. Knowledge Base
5. Historical journals
6. Backtests

The AI always prefers documented evidence.

---

# Golden Rules

- Memory supports conversations.
- Knowledge supports decisions.
- Strategy is never modified automatically.
- Permanent learning requires documentation.
- The AI explains when memory is insufficient.

---

# Long-Term Vision

The Memory System enables Traders World AI to feel like a long-term trading partner while remaining accurate, transparent, and faithful to the founder's documented methodology.
